
1 Sistema de Controle de Estoque em C

2 Sobre o projeto
Projeto acadêmico desenvolvido em linguagem C
para simular o gerenciamento de produtos de
um pequeno estabelecimento comercial.

3 Funcionalidades
- Cadastrar produtos com nome, preço e quantidade.
- Listar os produtos cadastrados.
- Atualizar a quantidade de produtos no estoque.
- Consultar os dados pelo terminal.

4 Tecnologias utilizadas
- Linguagem C
- Entrada e saída de dados pelo terminal

5 Conceitos aplicados
- Variáveis e vetores
- Estruturas condicionais
- Estruturas de repetição
- Laços e comandos de seleção

6 Como executar
1. Acesse um compilador de linguagem C.
2. Abra o arquivo main.c.
3. Compile e execute o programa.
4. Utilize o menu para acessar as funcionalidades.

7 Observação
Os dados são armazenados apenas durante a
execução do programa.
